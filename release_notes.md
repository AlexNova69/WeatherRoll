# 🌦 WeatherRoll v1.1.0 — полноэкранный прогноз погоды для эфира и табло

![Сейчас](https://raw.githubusercontent.com/AlexNova69/WeatherRoll/main/screenshots/icon_sun.png)

**WeatherRoll** — комплект для полноэкранного показа погоды в городе: QML-скрипт
для титровального ПО «Форвард Т» (FDTitle Designer / FDOnAir) и автономных
киосков/табло + сборщик данных с открытым API Open-Meteo, умеющий работать
службой Windows с автозапуском. Никаких ключей и регистраций — скачал,
указал город, запустил.

## 📡 Сборщик WeatherCollector

* **Открытые данные без ключей**: Open-Meteo (геокодинг + прогноз), ввод города
  на русском: `WeatherCollector.exe --city "Тихвин"`, проверка: `--search "тихв"`.
* **Повышенная точность для РФ**: усреднение трёх моделей — best_match + GFS +
  ICON (отключается в ini).
* **Период 10–60 минут**, атомарная запись UTF-16 LE с BOM — скрипт никогда
  не видит «полуфайл»; при сбое сети старые данные сохраняются, ошибки —
  в журнал с повторами.
* 🪟 **Служба Windows с автозапуском** после перезагрузки: правый клик по
  `install_service.bat` → «Запуск от имени администратора». Управление:
  `WeatherCollector.exe stop | restart | remove`. В списке служб —
  «WeatherCollector — сборщик погоды (WeatherRoll)».
* 📋 **Журнал с самоочисткой**: `log_days = 3` — записи старше трёх дней
  удаляются автоматически, `log_file = off` — файл не пишется вовсе.

## ⚙️ Настройки без правки кода

FDTitle Designer не показывает пользовательские свойства QML, поэтому все
настройки показа вынесены в **WeatherRoll.ini** рядом со скриптом — с
комментарием у каждого параметра:

```ini
backgroundImageUrl =  ; фоновая картинка jpg/png
introVideoUrl =       ; видео-заставка перед показом
outroVideoUrl =       ; видео в конце показа
musicUrl =            ; музыка wav/mp3
splashDurationMs =    ; длительность заставки 3000..8000
transitionStyle =     ; flip | slideLeft | slideRight | slideUp | slideDown
sectionTimes =        ; Сейчас=8000;Завтра=12000
showWeatherIcon =     ; анимационные иконки вкл/выкл
```

Ini перечитывается вместе с данными — фон, переходы и тайминги меняются
без перезапуска показа.

## 📄 Формат файла погоды

```text
Прогноз погоды в Тихвине
#Сейчас
Температура: +9°C, Ощущается: +7°C, Ветер: ЗЮЗ 3-6 м/с, Давление: 761 мм рт.ст., пасмурно, влажность 87 %
#Сегодня
ночью +8°C, утром +6°C, днем +9°C, вечером +7°C, днем пасмурно, ветер ЗЮЗ до 6 м/сек, без существенных осадков
#Завтра
ночью +5°C, утром +3°C, днем +8°C, вечером +6°C, днем облачно с прояснениями, ветер Ю до 4 м/сек, осадки: 2 мм (60%)
```

«ночью +8С» → квадрат с крупной температурой; «Подпись: значение» → квадрат;
остальное — строка описания. Файл можно править вручную (Блокнот, UTF-16/UTF-8).

## 🚀 Установка

**Быстрый старт (Windows):**
1. Скачайте `WeatherCollector.exe` из вложений релиза в свою папку.
2. `WeatherCollector.exe --city "Ваш город" --out <путь>\weather.txt` — создаст ini и начнёт цикл (или установите службой через `install_service.bat`).
3. Подключите `WeatherRoll.qml` в FDTitle Designer на весь экран (соседние
   `WeatherRollAV.qml`, `WeatherRoll.ini` — в ту же папку) либо запустите
   автономно: `qml.exe WeatherRollStandalone.qml`.

**Из исходников:** Python 3.8+, `build_exe.bat` пересоберёт exe
(PyInstaller + pywin32 установятся автоматически).

* 🔤 Крупный заголовок секции на каждом слайде вместо вкладок.
* 🔢 Цифры в квадратах увеличены до ~размера квадрата, описание — крупный
  жирный шрифт по размеру плашки.
* ⚙️ Все настройки — в WeatherRoll.ini с комментариями, горячая перезагрузка
  вместе с данными.
* 📄 Выходной файл — атомарная запись UTF-16 LE с BOM; служебная секция
  «Обновлено» убрана, источник — мелкая подпись на экране.
